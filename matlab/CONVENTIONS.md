Coordinate System:
Right-handed

Inertial Frame:
I = Earth-centered inertial frame

Body Frame:
B = spacecraft body-fixed frame

Quaternion:
q_IB = [qw qx qy qz]^T

Quaternion ordering:
scalar-first

Quaternion convention:
Hamilton

q_IB meaning:
rotation from body frame B to inertial frame I

Angular velocity:
ω_BI^B

Meaning:
angular velocity of body B relative to inertial frame I,
expressed in body coordinates

Units:
SI

Angles:
radians internally
degrees only for plotting/user input
